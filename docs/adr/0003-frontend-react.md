# ADR 0003: Frontend: React vs Next.js

- **Status:** Accepted
- **Date:** 2026-10-13
- **Sources:** `docs/decisions-draft.md`, `docs/requirements.md`

## Context

The website has public pages (landing page, facilities, gallery, events, booking request form, FAQ, footer) and an admin page (`requirements.md`).

`R1.md` records nothing that bears on this choice.

## Options

| Option | Reasoning recorded |
|---|---|
| React | "high familiarity" (`decisions-draft.md`) |
| Next.js | None recorded; not mentioned in `decisions-draft.md` |

## Decision

React, because of high familiarity.

## Consequences

None recorded yet.
