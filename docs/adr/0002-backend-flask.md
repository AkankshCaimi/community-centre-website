# ADR 0002: Backend framework: Flask vs FastAPI

- **Status:** Accepted
- **Date:** 2026-10-13
- **Sources:** `docs/decisions-draft.md`, author's answer on 2026-10-13

## Context

The website needs a backend for the booking request form and the admin page (`requirements.md`).

`decisions-draft.md` listed both frameworks without choosing between them. The author confirmed the choice on 2026-10-13.

`R1.md` records nothing that bears on this choice.

## Options

| Option | Reasoning recorded |
|---|---|
| Flask | "high familiarity" (`decisions-draft.md`) |
| FastAPI | "most popular option" (`decisions-draft.md`) |

## Decision

Flask, because of high familiarity.

## Consequences

None recorded yet.
